# AgentGuard

> **Project status: sunset / discontinued.**

BLCCoreStudio has decided to end active development of AgentGuard as part of a deliberate reduction in project count and maintenance load.

AgentGuard explored explainable safety checks for AI-assisted development workflows, including command policy checks, prompt-risk scanning, Git metadata policy and optional Linux sandboxing. The current implementation remains available for reference, but **no further feature development or routine maintenance is planned**.

This repository may later be made private or removed after the portfolio cleanup is complete.

## Why development ended

The project accumulated several security and policy surfaces that would require continuous maintenance as agent tooling evolves. BLCCoreStudio is concentrating on a smaller set of projects that can be maintained deeply rather than keeping overlapping experimental tools active.
